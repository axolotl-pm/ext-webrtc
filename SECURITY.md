# Security Policy

## Supported Versions

Only the latest version receives security updates.

## Scope & Limitations

* **Upstream bugs:** This project is a PHP binding. If the vulnerability is in `libdatachannel` itself, report it directly to the upstream repository.
* **Low-severity DoS:** Denial of Service (DoS) issues that only freeze a self-connection are considered low severity.
* **Patch delays:** Updating and shipping PHP extensions for PocketMine is a slow process. Expect delays for low-severity patches.

## Reporting

Do not open a public issue for security vulnerabilities.

Use GitHub's Private Vulnerability Reporting instead:
1. Go to the **Security** tab.
2. Click **Report a vulnerability**.
